## 3. 实现细节

### 3.1 数据库字典表使用

文件类型和文档类型将从字典表中读取：
- 文件类型字典：t_dict(dictCode='document_file_type')
- 文档类型字典：t_dict(dictCode='document_doc_type')
- 标签字典：t_dict(dictCode='document_tag')

### 3.2 主要功能说明

#### 查询功能
- 支持按文档名称模糊搜索
- 支持按文件类型过滤(支持多个)
- 支持按文档类型过滤(支持多个)
- 支持按标签ID过滤
- 支持按文档ID查询历史版本

#### 标签管理
- 支持添加文档时选择标签
- 支持更新文档时修改标签
- 详情接口返回完整的标签列表
- 标签列表通过中间表关联查询

#### 版本管理
- 新增文档时自动保存历史版本
- 更新文档时自动保存历史版本
- 支持按文档ID查询历史版本列表
- 支持删除文档所有历史版本

#### 权限控制
- 只有文档创建人可以查看、编辑、删除该文档
- 使用 Sa-Token 进行登录验证
- 使用 StpUtil 进行权限校验

## 4. 接口列表

### 文档主表接口
- POST /tDocument/queryPage - 分页查询
- GET /tDocument/getDetail/{id} - 详情
- POST /tDocument/add - 添加
- POST /tDocument/update - 更新
- POST /tDocument/batchDelete - 批量删除
- DELETE /tDocument/delete/{id} - 单个删除
- GET /tDocument/getSystemTags - 获取系统预设标签
- GET /tDocument/getFileTypeDict - 获取文件类型字典
- GET /tDocument/getDocumentTypeDict - 获取文档类型字典

### 文档版本历史表接口
- POST /tDocumentVersion/queryPage - 分页查询
- GET /tDocumentVersion/getDetail/{id} - 详情
- POST /tDocumentVersion/add - 添加
- POST /tDocumentVersion/update - 更新
- POST /tDocumentVersion/batchDelete - 批量删除
- DELETE /tDocumentVersion/delete/{id} - 单个删除
- GET /tDocumentVersion/queryByDocumentId/{documentId} - 根据文档ID查询历史版本列表
