MJS基地“布洛德峰”轮生产工作总结

本次作业在 621“大汉”轮首艘外轮靠泊基础上开展，成功克服基地建设交叉作业等不利影响，临时供电与控制安全可靠。卸船机、斗轮机及皮带流程设备运行总体稳定，生产组织与应急保障平稳有序，作业效率指标显著提升。较“大汉”轮作业，船时效率提升51.9%，净船时效率提升65.6%，设备故障时间占比从24.17%降至16.83%，实现生产效能与设备稳定性的双重突破。

4.稳泊情况

本次靠离泊期间，整体风速5-6级阵风7级，风浪2级，中大潮汛（农历初三至初七），最大潮差4m。期间整体稳泊情况可控。本次靠泊码头系泊绞车艏艉各使用二台，在结合船上缆空、系缆柱布置，该轮的缆绳布置为艏艉各5-3-2。

船舶在泊稳泊正常，靠泊后出现短暂性船尾离档启动拖轮顶推贴回，其余在泊时段3艘大马力拖轮均处于船边停车保驾状态，未进行顶推作业。

（三）主要设定指标完成情况

1．指标一：测试 4 台卸船错峰协同作业。 本次作业使用 1#、2#、3# 三台卸船机同时作业。经测试 1#、2#卸船机实现了错峰作业，作业顺畅。

2．指标二：平均稳定流量达到 4000 吨/小时。本次平均稳定流量约4500—5300t/h（持续 4 小时以上）。  

2.       设施设备情况

本次作业临时供电供水设施设备运行良好，卸船流程设备运行总体稳定。

1.       临时供电情况

供电线路及供电设备运行稳定。现场人员使用热成像仪巡查，供电线路各接头无明显发热情况，整条架空线发热均匀，温升保持在7～8摄氏度；码头变电所供电设备、临时环网柜、临时箱变运行期间均未发生故障。

（二）供水设备情况

    供水设备运行稳定。卸船机、皮带机、转运站内启用永久供水管道供水，运行良好。斗轮机继续采用临时供水保障，达到用水要求。

（三）作业设备情况

本次作业设备运行期间，共出现停机48次，影响生产总时间为15.25小时。

1.斗轮机：主要故障为中继皮带跑偏（停机72分钟）。现场处理完成。

2.皮带机：主要故障为BX1A皮带重跑偏和清扫器修理（停机385分钟）。现场处理完成。

3.卸船机：主要故障为1#卸船机第一次重载试车，部分程序参数需要现场设定。现场处理完成。

经分析，影响生产流程与设备的故障停机，主要集中在卸船机落料点调节不准、皮带机纠偏能力较弱，导致过机皮带跑偏多次；斗轮机尾车落料点调节不准引起停机处理等。

计划通过优化卸船机倒料槽缓冲梁调节板增强落料点调节能力，斗轮机尾车料斗增设调节装置，BX1A皮带增加纠偏装置，降低皮带跑偏风险。

3.       生产作业情况分析

（一）       生产指标大幅提升

“大汉”轮：船时效率1683t/h，净船时效率1856t/h;“布洛德峰”轮：船时效率2556t/h，净船时效率3074t/h。对比船时效率提升51.9%和净船时效率提升65.6%。

本次效率提升的关键要素有：

1.设备故障时间占比大幅下降

“大汉”轮作业时间50.58小时，故障12.23小时，占比24.17%。“布洛德峰”轮作业时间90.59小时，故障时间15.25小时，占比16.83%。

具体举措：

（1）       避免上条船同类型故障再次发生。

本次作业前对“大汉”轮作业中出现的1小时以上故障进行及时消缺和应急措施，如斗轮机中继皮带张紧不足、斗轮机控制盒跳闸故障、卸船机斗门打不开、皮带机水冷泵故障等问题。

（2）       重点关注本船第一票货物作业期间发生的皮带跑偏故障，加强重要部位的人员力量。

通过加强BX1A皮带、斗轮机中继皮带等重点部位的人员巡检力量，提前预判皮带跑偏趋势、及时纠偏、避免停机，在本船第二票货物作业期间大幅降低故障占比时间（从23.96%降至3.83%），提高作业连续性。

纽曼粉作业58.51小时，故障时间14.02小时，占比23.96%。津布巴粉作业32.08小时，故障时间1.23小时，占比3.83%。

2.清舱效率提升

本次作业共清9个舱，采用挖机+单斗清舱，平均挖机作业时间8.48小时，平均单斗作业时间1.8小时，平均单舱清舱时间10.28小时，较“大汉”轮平均单舱清舱时间12.73小时，效率提升19.25%。

3.加强团队协同，提高人机配合度

本船第一票货物作业时发生卸船机落料点调节不准、BX1A皮带纠偏能力不足导致严重跑偏；斗轮机中继皮带跑偏等长时间停机处理。（6月29日白班瞬时流量图，流量不稳定）

 

6月29日白班 瞬时流量图

第二票货物作业时（6月30日夜班开始），团队及时从生产组织协调上下功夫，加强中控统一指挥调度，组织卸船机、皮带机、斗轮机沿线精准配合，做到3台卸船机有序放料、精准落料，未发生皮带跑偏引起的故障停机。

6月30日夜班，流程运转时间691min（其中负荷时间643min），进场作业量48939t，净作业效率4567t/h，总作业效率4249t/h。

（二）设备问题逐步聚焦，消缺持续优化

随着重载过程消缺，小问题逐步销号减少，重点聚焦影响生产流程与设备的故障停机，主要集中在卸船机落料点调节不准、皮带机纠偏能力较弱，导致过机皮带跑偏多次；斗轮机尾车落料点调节不准引起停机处理等。

本次作业进行了短时的大流量测试，最大瞬时流量达8000t/h,通过性总体可靠。但6500t/h以上流量时局部位置易出现溢料、过机长皮带纠偏能力弱等缺陷，造成皮带跑偏停机频次高、处理调整时间较长。

计划在下艘次卸船前完成以下重点消缺项：1.卸船机倒料槽缓冲梁调节板增强落料点调节能力；2.斗轮机尾车料斗增设调节装置；3.BX1A皮带增加纠偏装置，降低皮带跑偏风险。

四、       下一步工作思路

（一）坚持全员牢固树立“将每一艘次作为首靠船对待”的安全底线思维与归零意识。

清晰厘清边生产边建设的参建、运营操作等单位多方的责任边界，基地切实履行安全、质量主体责任；明确鼠浪湖公司作为生产作业主体，切实发挥主人翁意识，全面负责生产运营，系统排查安全隐患与设备缺陷；各设备设施厂家全力配合设备调试与消缺闭环落实；各建设单位坚决执行生产运营统一指令，以如履薄冰的实际行动确保船舶靠离泊、稳泊安全，接卸作业安全、顺畅、有序、高效。

（二）作业人员相对固定、优化交叉交班

经过三艘次作业磨合，作业人员已初步熟悉作业环境、生产设备及外部保障条件，正从认知阶段向熟练操作过渡。团队成员相对固定有助于默契度提升，统筹协调卸船机、皮带机、斗轮机等跨环节作业流程，有效保障生产运营的连续性。

优化交叉交班，调度和中控在换班时候，须在现场充分交底、协同指导，直至流程稳定后才能离岗，为后续高效作业奠定坚实基础。

（三）完善生产调度协同机制

继续推行“中控—设备—现场”三位一体调度模式，由中控统一协调卸船机错峰放料节奏，通过实时监测皮带机流量（如保持 5000t/h 以上稳定区间）优化各环节配合精度，避免因落料偏差导致皮带跑偏，引起停机。

（四）优化货种作业工艺与流程衔接

针对不同物料的物理特性差异（如密度、含水量），制定分货种作业工艺。如根据不同物料控制卸船机大料斗存料数量，选择合适的斗门开度、振动给料器速度等。

（五）进一步取得联建单位支持

加强与海事、边检、海关等联检单位的沟通，主动对接政策导向为企业争取便利化措施，赢取更大支持。

一、首靠外贸船，MJS基地卸船净作业效率、人均船时效率均高于鼠浪湖码头，但船时效率略低于鼠浪湖码头。分析如下：
（一）鼠浪湖作业人数多于MJS基地，MJS基地84人，鼠浪湖首靠115人。主要因为倒班模式不同：赛维娜轮开港初期采用三班三倒模式；MJS基地大汉轮接卸采用两班两倒模式，人力用工数量大幅降低，但也存在作业连续性困难（布洛德峰轮作业时就需要换班休息）。
（二）故障停机时间MJS基地多于鼠浪湖。主要原因：
1.鼠浪湖安装调试时间长。鼠浪湖作业前安装调试共307天，MJS基地作业前安装调试共114天。
2.鼠浪湖设备保障人员投入多。鼠浪湖借助北仑矿石码头技术力共同参与（北矿6人+鼠浪湖19人）总计技术保障人员投入25人；MJS基地投入技术保障人员9人（鼠浪湖8人+基地1人）。
3.MJS基地设备保障难度大，9人在兼顾临电、临控的条件下设备保障力量偏弱，导致故障停机时间高于鼠浪湖码头。
（三）MJS基地清仓等待时间长。两船均为2台卸船机单流程作业，赛维娜轮1票货9个舱全清，作业过程基本可处于满负荷抓料作业状态；而MJS基地大汉轮2票货5个单舱清舱，卸船机进入清仓状态可调节满斗抓料余地不大，清仓过程卸船机等待时间较长，耗时3.12小时。
二、首靠25万吨外贸船，所有指标均高于鼠浪湖首靠船。
（一）设备故障时间占比下降。“塞维娜”轮作业时间86.5小时，故障16.35小时，占比18.9%。“布洛德峰”轮作业时间90.59小时，故障时间15.25小时，占比16.83%。
（二）清舱效率提升。本次作业共清9个舱，采用挖机+单斗清舱，平均挖机作业时间8.48小时，平均单斗作业时间1.8小时，平均单舱清舱时间10.28小时，无卸船机等待时间。
（三）人机配合逐渐熟练。经过三艘次作业磨合，作业人员已初步熟悉作业环境、生产设备及外部保障条件，正从认知阶段向熟练操作过渡。团队成员协作默契度显著提升，6月30日夜班开始作业效率长时间稳定在5000t/h,当班净作业效率达到4567t/h（当班作业量48939t，净作业时间10.72h）。
